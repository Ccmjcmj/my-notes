# 📚 操作系统

操作系统学习路线（高级前端视角）：进程线程、内存、IO 异步，以及与网络、浏览器的关系。

> **优先级说明：** 🔴 核心必学 · 🟡 了解/衔接 · 🟢 拓展加分

## 《操作系统》学习路线

（理解为主，不用啃大部头）
很多前端遇到的事件循环、进程线程、浏览器架构根源都在这里。

1. **进程和线程（重中之重）**
浏览器多进程架构
2. 阻塞、非阻塞，同步、异步；JS 单线程，Web Worker
3. IO 模型（弄懂异步 IO 即可，select/poll/epoll 简单了解，不用深究源码）
4. 内存基础概念：堆、栈
5. 端口，Socket 属于操作系统资源（解释为什么端口不能重复占用）
