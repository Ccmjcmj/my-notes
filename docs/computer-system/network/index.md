# 📚 计算机网络

计算机网络学习路线：从 TCP/IP 骨架到应用层、传输层，再到前端工程实战。

> **优先级说明：** 🔴 核心必学 · 🟡 了解/衔接 · 🟢 拓展加分

## 《计算机网络》学习路线

>1. 网络分层模型（OSI 七层 / TCP/IP 四层，重点：四层模型）
>2. IP、端口、socket 套接字
>3. TCP/UDP 区别，三次握手，四次挥手，拥塞控制（看懂基础原理，不用深入内核算法）
>4. HTTP 1.0 / 1.1 / 2 / 3 差异；请求报文，响应报文
>5. HTTPS 加密流程（TLS，证书）
>6. 缓存机制：强缓存，协商缓存
>7. 跨域原理，CORS，OPTIONS 预检请求
>8. 正向代理，反向代理（Nginx 内部转发）
>9. WebSocket 底层原理，和 Socket 区别
>10. DNS 解析完整流程

## 前端最优学习顺序（从你感知到的东西往里推）

1. **应用层（http/https）**
>
>你每天写 fetch、看控制台网络面板，最有体感。<br>
>学习内容：请求行，请求头，响应头、缓存、跨域、CORS、Cookie、https TLS 流程

2. **传输层 TCP & UDP**
>
>套接字 Socket，端口，三次握手，四次挥手，流量控制<br>
>重点搞懂：连接是什么，端口作用，客户端 vs 服务端口，Nginx 网关转发整套逻辑

3. **网络层 IP、NAT、路由、ICMP**
>
>公网/私网 IP、NAT 与代理、路由与 CDN、ping 排查<br>
>DNS 解析见应用层；ARP 了解即可

4. **数据链路层、物理层**
>
交换机、以太网、信号调制这类，前端尽量浅看，不用深挖。

## 计网怎么学？

>解决 “概念空洞” 手段：**动手抓包（重中之重）**<br>
>看书 10 遍不如抓包 1 次。工具推荐：

>1. 浏览器 DevTools → Network（入门首选）<br>
>观察请求端口、状态码、请求头、缓存，排查跨域。<br>
>2. Wireshark（进阶，查看真正 TCP 数据包）<br>
>可亲眼见：SYN，ACK 握手包，TCP 分段。<br>
>你就能直观验证这套流程：创建套接字 → 发起握手 → TCP 连接 → http 报文传输。

>推荐一个实操任务：立刻抓包
>打开 B 端，用 Wireshark 过滤 443 端口流量，观察：

>1. 浏览器向外发包目标 IP：443
>2. 看见三次握手数据包
>3. 理解：你只能看到到 443，服务器内部转发对你透明

>实操原则：学到一个概念，立刻找工具验证。遇到不懂名词，定向跳转到对应章节看。

>书籍：《图解 http》必看。薄，通俗，应用层入门神器。

>自检清单（能流畅口述整条链路）
### 浏览器输入 B 端网址按下回车，从头到尾发生了什么？

>1. DNS 域名解析，得到服务器 IP
>2. 浏览器创建客户端 Socket（生成本机随机端口）
>3. connect 发起 TCP 三次握手，和服务器 443 端口建立 TCP 连接
>4. TCP 连接之上进行 TLS 握手，建立 HTTPS 加密通道
>5. 发送 HTTP 请求报文
>6. Nginx 接收请求，内部转发到对应的微服务
>7. 业务程序处理，返回响应
>8. 浏览器渲染页面
>9. 空闲后关闭 TCP 连接，四次挥手，回收套接字

## 深度理解 VS 仅了解概念

>### ① 深度理解（能讲清楚原理，排查问题）

>http 系列、HTTPS、TCP、Socket、端口、DNS、正向 / 反向代理、跨域、缓存、WebSocket

>### ② 仅了解

>拥塞控制详细算法，滑动窗口细节，路由协议，ARP，交换机工作原理
