# 📚 Nginx（前端方向）

高级前端方向的 Nginx 学习路线，聚焦静态部署、反向代理与跨域。

> **优先级说明：** 🔴 核心必学 · 🟡 拓展了解 · 🟢 可跳过

>✅ 定位：前端不用吃透底层 C 源码、负载均衡算法细节，重点是**前端日常会配置、排查、面试常考**，主要用于静态资源托管、反向代理、跨域、SPA 路由、缓存、gzip 压缩等。

## Nginx学到什么程度才够用？
### 🔴务必掌握：
>1. 正向代理、反向代理区别
>2. proxy_pass 反向代理配置原理
>   - 场景：前端静态资源托管、接口代理（解决开发环境跨域，线上请求转发）
>3. 静态资源服务：托管 html/js/css，缓存配置(expires)
>4. 理解 80/443 端口，HTTPS证书基础配置概念
>5. 区分：Nginx内部转发(proxy‑pass) vs 301/302重定向
>6. 看懂基础错误：403，499，502，504 大概什么原因
>7. 本地能搭一套简易环境测试：
>访问 http://localhost，Nginx转发到 127.0.0.1:3000

## 前端为什么要学 Nginx？3个真实工作场景
1. 本地开发代理(最高频)
>Vite/Webpack devServer 的 proxy，思想和 Nginx 反向代理一样懂Nginx，你彻底理解开发代理为什么能解决跨域；

2. 前端项目部署
>①静态页面打包后，很多公司可用 Nginx 托管；<br>
>②路由 history 模式，必须配置 try‑files，不然刷新页面404，很多前端就是不懂这块

3. 沟通协作，听得懂后端 / 运维话术
>运维说：**网关 Nginx 转发失败、502 网关错误**；<br>
>如果你不懂反向代理，根本无法一起排查线上问题

# 极简单学习路线（适合前端）

> 
> 计网只教理论，不会教 Nginx；Nginx 属于工具课

>1. 安装 Nginx
>2. 实现第 1 个案例。Nginx 监听 80，转发请求到本地 3000 端口的前端服务（`proxy‑pass`）
>3. 实现 history 路由配置，解决 404
>4. 配置静态资源缓存
>5. 简单了解 https 证书配置（看懂即可，不用自己生成部署）

## 常见误区

> 
> “我是前端，项目有运维，Nginx 不归我管，可以不学”

>中小型公司基本都是前端自己负责部署前端资源；就算大公司有运维，面试高级前端非常喜欢问反向代理、history 模式 Nginx 配置，属于高频考点。
