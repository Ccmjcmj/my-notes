# 计算机体系知识

欢迎来到计算机体系知识分类，这里主要涵盖操作系统、计算机网络、组成原理等内容。

> **优先级说明：** 🔴 核心必学 · 🟡 了解/衔接 · 🟢 拓展加分

## 全栈知识点齐问题汇总

学习路线：

>1. 计算机网络
>2. 操作系统
>3. 浏览器底层原理（结合上面两块知识，瞬间融会贯通）
>4. 数据结构基础 + 基础算法
>5. AST，编译原理基础（工程化方向再深入）

关键避坑：

>1. 不要一上来啃完整大学教材。（课本大量硬件、底层理论和前端无关，越学越迷茫）
>2. 理论一定要搭配工程例子。（学到反向代理、本地搭 Nginx 测试；学到 TCP，抓包看请求）
>3. 分清看懂原理和精通底层源码。（高级前端只需懂原理，能解释现象、排查问题，不用操作系统、网络协议源码）

区分标准：什么程度才算合格高级前端

>看到一个现象，能从底层找原因。举例：
>接口跨域 → 立刻想到浏览器同源策略 + CORS
>页面卡顿 → 区分是 JS 阻塞，回流重绘，网络慢
