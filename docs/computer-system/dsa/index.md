# 📚 数据结构与算法

高级前端方向的数据结构与算法学习路线。

> **优先级说明：** 🔴 核心必学 · 🟡 了解即可 · 📌 学习建议

## 《数据结构与算法》学习路线（分档位，不盲目刷题）

>### 必懂概念（高级前端必备）

>1. 基础结构：数组，链表，栈，队列，哈希表（Object/Map 底层）
>2. 树：二叉树，DOM 树，虚拟 DOM 本质就是树结构
>3. 时间复杂度、空间复杂度基础概念

>### 算法要求

>1. 初 / 高级前端：掌握基础排序，二分查找，递归；
>2. 不建议一上来刷几百道 LeetCode；优先结合业务场景刷题。
>（大部分前端业务，极少用到复杂算法；面试常考基础算法）
